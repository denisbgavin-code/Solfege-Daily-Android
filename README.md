# Сольфеджио: игра каждый день

Android-приложение для последовательных игровых микроуроков сольфеджио для детей первого года обучения в ДМШ/ДШИ.

Курс: 34 недели × 7 ежедневных занятий = 238 уроков. Тематическая последовательность совместима с:
- А. А. Варламова, Л. В. Семченко — «Сольфеджио. 1 класс»;
- Е. М. Золина — «Домашние задания по сольфеджио. 1 класс».

Упражнения приложения оригинальные и не воспроизводят задания из книг.

Методическая логика: сначала слух и движение, затем воспроизведение, название, нотная запись, творческое применение и интервальное повторение.

Приложение работает офлайн, без рекламы, аккаунта и доступа к микрофону.

APK автоматически собирается GitHub Actions и публикуется как workflow artifact.
