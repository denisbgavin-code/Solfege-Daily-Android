# Музыкальная экспедиция — сольфеджио каждый день

Android-приложение для детей первого года обучения музыке: короткие ежедневные уроки по 5–10 минут, в которых ребёнок сначала **слышит и действует**, а уже потом видит термин и нотный знак.

## Что изменено в v2

- интерфейс перестроен в формат одной понятной задачи на экран;
- инструкции переписаны для ребёнка 7 лет: коротко, с конкретным действием и без методической терминологии в детском интерфейсе;
- добавлена отдельная проверка звука;
- аудиодвижок переведён на Android media stream и потоковый AudioTrack;
- добавлены слуховые мини-игры, ритмический тап-тренажёр, мелодический контур и нотный стан;
- учебник и рабочая тетрадь больше не требуются во время урока: всё нужное для выполнения задания находится в приложении;
- курс больше не следует страницам одного пособия. Российская программа первого года используется только как контроль покрытия тем;
- каждый день включает слух, движение/ритм, голос, визуализацию музыки и собственный музыкальный ответ ребёнка.

## Педагогическая модель

Траектория объединяет практики Kodály, Orff-Schulwerk, Dalcroze Eurhythmics, Gordon Music Learning Theory и Feierabend Conversational Solfege, а также общие принципы retrieval practice и spaced review. Приложение не объявляет одну школу «лучшей»: используются те элементы, которые подходят конкретной задаче.

Основная последовательность:

**услышать → почувствовать движением → повторить → распознать → увидеть знак → применить → придумать своё → вернуться к материалу позже**

Для чтения используются фиксированные русские названия нот, а для ладовой функции — номера ступеней. Это позволяет сохранить совместимость с российской практикой сольфеджио и одновременно тренировать функциональный слух.

## Годовой охват

34 недели × 7 дней = 238 микроуроков. В течение года покрываются: пульс, метр, 2/4, 3/4, 4/4, четверти, восьмые, шестнадцатые, паузы, затакт, мажорная гамма, тоника и устойчивость, ступени, До/Соль/Фа/Ре/Си-бемоль мажор, транспонирование, основные интервалы, секвенция, канон и сопоставление одноимённых ладов.

Пособия А. А. Варламовой / Л. В. Семченко и Е. М. Золиной используются как ориентир того, что ученик первого класса ДМШ должен встретить в течение года. Упражнения внутри приложения оригинальные и не копируют защищённые авторским правом задания из этих книг.

## Приватность

Приложение работает офлайн, без рекламы, аккаунта, аналитики и доступа к микрофону.
